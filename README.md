# Banking-system

DISCLAIMER: This program is not to be shared or copied without proper authorization from myself. Keep in mind this program may not be able to be used to its full capacity without other programs. 

The provided code implements a simple banking system with multi-threading capabilities, allowing users to create accounts, modify balances, and run benchmarks to measure performance under various conditions. The system is structured into several components: the main program, a bank interface, and a benchmark driver. The main program uses a ledger_t structure to manage a linked list of accounts (account_t), each containing an account number, balance, and a pointer to the next account. It ensures thread safety by using a global mutex lock for ledger operations. Functions like create_account, list_accounts, and modify_balance allow users to interact with the ledger, while run_benchmark executes performance tests with varying numbers of threads and accounts, writing results to a CSV file. The bank interface provides a simpler, non-thread-safe implementation of account management, and the benchmark driver measures the system's performance by creating threads to simulate concurrent account creation and balance modifications. The benchmark results are calculated using CPU time metrics from getrusage. Overall, the code demonstrates a modular approach to building a multi-threaded application, with a focus on thread safety, performance benchmarking, and user interaction. It serves as a practical example of handling concurrency and measuring system scalability in C.
